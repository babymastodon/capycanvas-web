На компьютере можно скопировать папку `workspaces`, чтобы сохранить резервную копию рабочих пространств, панелей инструментов, палитр и настроек кистей {appName}. Рисунки, сохранённые в файлах `.capy`, находятся отдельно от этой папки. Параметры, импортированные текстуры бумаги и цветовые профили также хранятся отдельно.

## Места хранения

Ниже указаны папки установленного выпуска {appName}. `~` означает домашнюю папку.

| Установка | Папка рабочих пространств |
| --- | --- |
| Установщик Windows или ZIP | `%LOCALAPPDATA%\CapyAtelier\CapyCanvas\workspaces` |
| Windows MSIX | В `%LOCALAPPDATA%\Packages` откройте папку, имя которой начинается с `CapyAtelier.CapyCanvas_`, затем `LocalState\workspaces`. |
| macOS | `~/Library/Containers/art.capycanvas.CapyCanvas/Data/Library/Application Support/art.capycanvas.CapyCanvas/workspaces` |
| Linux | `~/.local/share/capycanvas/workspaces` |
| Flatpak | `~/.var/app/art.capycanvas.CapyCanvas/data/capycanvas/workspaces` |
| Android | Внутри приложения. |
| iPad | Внутри приложения. |
| Web | Внутри браузера. |

На Android, iPad и в веб-версии нельзя скопировать эти папки из {appName}.

## Создание резервной копии

Можно сохранить копию всей папки в другом месте.

Чтобы создать резервную копию папки:

1. Завершите все работающие копии {appName}.
2. Откройте родительскую папку указанной выше папки `workspaces`.
3. Скопируйте всю папку `workspaces` в место для резервной копии.

## Восстановление резервной копии

Можно заменить текущую папку рабочих пространств резервной копией. Восстановление заменяет изменения рабочих пространств, панелей инструментов, палитр и настроек кистей, сделанные после создания копии.

Чтобы восстановить папку:

1. Завершите все работающие копии {appName}.
2. Переместите текущую папку `workspaces` в другое место.
3. Скопируйте резервную копию в исходное место под именем папки `workspaces`.
4. Откройте {appName}.
